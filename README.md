# أجاري — منصة الاستئجار

**كل ما تحتاجه، تقدر تستأجره.** منصة سوق عربية RTL لاكتشاف العقارات والسيارات والأزياء والإلكترونيات والمعدات والأثاث والمناسبات والرحلات.

## الوظائف الأساسية

- صفحة رئيسية متجاوبة، فئات بأيقونات متجهية محلية، واستكشاف حسب الموقع والقسم ووحدة السعر والميزانية والفترة.
- تفاصيل إعلان مع معرض صور يمكن التنقل بين صوره ومراجعات المالك الحقيقية.
- نشر إعلان وتعديله وإخفاؤه، ورفع صور JPEG أو PNG أو WebP من الجهاز إلى تخزين أجاري الدائم. يدعم الإعلان حتى 8 صور، بحد أقصى 6 ميغابايت للصورة، مع المعاينة والإزالة قبل الحفظ.
- وحدات سعر مناسبة لنوع العنصر: العقارات باليوم أو الأسبوع أو الشهر أو السنة؛ السيارات والإلكترونيات/الكاميرات بالساعة أو اليوم أو الأسبوع؛ وبقية الأقسام بوحداتها المحددة في `shared/rental.ts`.
- حجز مع احتساب مدة الإيجار على وحدة الإعلان. حجوزات الساعة تطلب تاريخ ووقت البداية والنهاية؛ شهور وسنوات الإيجار تحتسب بحدود التقويم. يفحص الخادم تداخل الطلبات ويحفظ السعر والوحدة وقت الحجز.
- لوحة مستخدم، انتقالات حالة للمالك والمستأجر، مراسلة محمية بين طرفي الطلب، وتقييم متبادل بعد الإكمال. رسوم الخدمة المقدرة 5%؛ لا يوجد تحصيل مالي في هذه النسخة.

بطاقات الإعلانات المعروضة بلا بيانات أعضاء حقيقية موسومة بأنها أمثلة توضيحية؛ لا تحجز أو تمثل مراجعات حقيقية.

## التقنية

React وTypeScript وVite وTailwind في العميل؛ Express وtRPC وDrizzle ORM وMySQL في الخادم؛ Manus OAuth لجلسة المستخدم. تخزن مراجع الصور المستقرة `/manus-storage/...` في قاعدة البيانات، وتنتقل الصور عبر واجهة الخادم فقط. إعداد GitHub يحفظ الشيفرة المصدرية.

## التشغيل والفحوص

```bash
pnpm install
pnpm dev
pnpm check
pnpm test
pnpm build
```

يلزم الاتصال بقاعدة البيانات وخدمات Manus لتجربة إجراءات الأعضاء ورفع الصور. يوفر Manus البيئة الآمنة لهذه الخدمات عند تشغيل التطبيق ضمن المشروع؛ لا تودع بيانات الدخول أو مفاتيح الخدمة في المستودع. يأخذ الخادم المنفذ من `PORT` (الافتراضي 3000)، ويجيب `/api/health` دون مصادقة.

قاعدة التطوير المدارة مشتركة مع البيئة المنشورة. ترحيلات Drizzle الإضافية في `drizzle/`؛ تغيير المخطط يؤثر في هذه القاعدة المشتركة ويجب أن يكون مقصودًا وإضافيًا قدر الإمكان.

## النشر

المستودع على GitHub يحفظ المصدر؛ GitHub Pages لا يشغّل خادم Express أو قاعدة MySQL ولا يصلح لتشغيل هذه المنصة كاملة. نشر التطبيق الكامل يستخدم `Dockerfile` لإنشاء حزمة العميل والخادم ثم تشغيل `node dist/index.js`، ويستخدم `/api/health` للتحقق من جاهزية الخدمة. النشر النهائي يتم عبر استضافة التطبيق المتصلة بالمشروع، لا من عنوان GitHub Pages.

## بنية الملفات

- `client/src/pages/`: الرئيسية، السوق، تفاصيل الإعلان، لوحة الحساب، نشر/تحرير الإعلان، والرسائل.
- `client/src/components/`: العلامة والترويسة والبطاقات وأيقونات الفئات المحلية.
- `client/public/manus-routes.json`: مسارات صفحات الويب.
- `shared/rental.ts`: وحدات التسعير وحساب المدة وصياغة الأسماء العربية.
- `server/routers.ts` و`server/marketplace.ts`: API والتحقق من المدخلات والملكية والطلبات.
- `server/storage.ts`: ربط التخزين الدائم الخاص بالمنصة.
- `drizzle/schema.ts` و`drizzle/`: جداول السوق وترحيلاتها.
- `plan.md` و`TODO.md`: نطاق المشروع ومخرجات التنفيذ المفتوحة.

## حدود هذه النسخة

تسجيل الدخول يستخدم Manus OAuth. لا تتضمن المنصة دفعًا إلكترونيًا أو تحققًا من الهوية أو إشعارات جوال؛ لا تعرض هذه الخدمات على أنها متاحة.
